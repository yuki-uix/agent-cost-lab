## 要做的五个动作

按「好做 → 难做」排。**做到第 3 条这次采集就已经有价值了**，4、5 是加分。

### 1. 中途换模型 —— 必做，最省事

聊十几轮之后，用模型切换换一个（Sonnet ↔ Opus 都行），**然后继续在同一个对话里聊**。

- 期望：`model_changed`
- 关键：换完要**接着聊**。换完就退出等于没采到

### 2. 跑一次 `/compact` —— 必做

对话长到一定程度后：

```
/compact
```

压缩完**继续聊几轮**。

- 期望：`messages_changed`
- 这是整个项目最关心的一种：它重写历史，正是「token 变少、钱变多」的典型场景

### 3. 加或删一个 MCP server —— 必做

在会话进行中改 MCP 配置，让工具列表变化，然后继续聊。

- 期望：`tools_changed`
- 第一份录音里工具集有 0 / 51 / 1 三种，但那是主 agent 和子 agent 的区别，**不是同一个对话里的变化**——所以这条真没测过

### 4. 改 system prompt —— 尽量

改 `CLAUDE.md` 然后继续，或者开关一个 skill。

- 期望：`system_changed`
- **不确定 Claude Code 会不会在会话中途重读**。做了没效果也是结果，不用纠结

### 5. 晾到缓存过期 —— **不用做**

这次录音用的是 **1 小时 TTL**（不是 5 分钟）。专门等一小时不值得。

如果你正好去吃个饭、开个会，回来接着聊，那就白捡一个样本。**别专门等。**

不用刻意凑数——**正常干活到自然结束就行**，只要把上面 1–3 穿插进去。真实工作流比凑出来的轮数值钱。
